# pepeuchiacluster
Ce repo ser a rendre reproductible un modèle de répartition d'agent IA en fonctions de la puissance disponible sur plusieurs machine, cela permet de repartir la charge de façon cohérente en fonction du modèle et de la machine. De cette façon plus besoin d'avoir de gros équipements et les ressources inutilisée son re-attribuer.
